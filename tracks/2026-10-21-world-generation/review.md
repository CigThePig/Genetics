# PR #140 Codex review follow-up

Reviewed six findings on ae15063d40, against submitted head 0ae4a82. All six are valid and addressed. This follow-up also recovers evidence that was inaccessible during initial publication. The original 36,000-tick endpoints and browser measurements remain historical; they are not relabeled as fresh measurements of the review patch.

## Findings and corrections

1. [All-zero biome weights](https://github.com/CigThePig/Genetics/pull/140#discussion_r4342485766): the editor/import validator rejects disabling every terrestrial biome. Direct generation also rejects it before modifying an existing grid, instead of silently choosing plains. Partial weight objects retain the generator's existing missing-key defaults. Enabled weights are resolved once per generation.
2. [Water-control description](https://github.com/CigThePig/Genetics/pull/140#discussion_r4342485774): the editor now describes lake-depth/runoff thresholds and terrain/rainfall dependence; it makes no drinking-source guarantee.
3. [Disabled-biome founder habitat](https://github.com/CigThePig/Genetics/pull/140#discussion_r4342485780): spawning retains the original connected, vegetated, water-accessible preference when available. If none exists it accepts existing main-component traversable land, then other real land. It never returns an unchecked random water position. An entirely impassable world with a positive founder count raises a clear error; zero founders remains valid. No resource, perception or survival guarantee is added. Valid sand-only and rock-only maps remain supported.
4. [Unavailable motion inputs](https://github.com/CigThePig/Genetics/pull/140#discussion_r4342485788): population figures are generated independently. Motion plotting checks all required raw gzip recordings and PPM backgrounds and explicitly skips the optional figure when inputs are absent. It does not substitute incompatible animal-summary JSON for motion frames. Corrupt present inputs still fail visibly.
5. [Incomplete provenance](https://github.com/CigThePig/Genetics/pull/140#discussion_r4342485793): new diagnostics hash every file under src, with sorted relative paths and byte lengths delimiting contents. Outputs include the algorithm, complete file list, Git commit and source dirty status. This covers noise, configuration defaults, transitive ecological code and new source files. Source-only exports still get a content hash, with null Git metadata. Historical six-file checksums are retained and explicitly identified as partial checksums; the original manifest pins ecological implementation to 146745176c7b92ab672df9f84dffe3fa7773c421 and baseline to 971e65604e4c688274f7a80bb570c4b5d435aee0.
6. [Browser-launch cleanup](https://github.com/CigThePig/Genetics/pull/140#discussion_r4342485799): server readiness and Chromium launch now execute inside the cleanup scope. Startup exit/error rejects readiness; optional browser cleanup is nested so the Vite child is terminated even if browser close fails. A controlled launch rejection with a real Vite child exits with status 1 instead of hanging. Hosted CI exposed a second readiness issue: coloured Vite output separates Local from its colon with ANSI codes. Both world browser runners now parse complete lines with terminal controls stripped; the cleanup regression explicitly enables colour and removes NO_COLOR to reproduce the CI condition. The initial follow-up CI run is retained as a failure, not reported as passing.
