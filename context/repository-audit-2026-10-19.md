## Behavior changes reviewers should expect

The default configuration already enabled simple herding and the behavior state machine, but neither setting was connected correctly. Activating those existing choices changes the trajectories and timing of the simulation. Paternal snapshots and birth placement change offspring outcomes; initial resource setup and seeded herd contagion also change RNG consumption. Old seeds remain replayable under the new implementation, but old recorded outcomes are not preserved bit-for-bit across this PR.

Async herding is deliberately not used to decide authoritative state. This avoids results depending on device speed or message arrival order. The tick ordering of the existing major systems has not been rearranged; behavior integration is in Decide/Act, and index refresh is a maintenance operation before LifeHistory reproduction.

## Remaining product/design work, not claims of completion

- Five simulated minutes is not evidence of indefinite population balance, rich emergent behavior or stable evolution. The soak suite reports outcomes; it does not impose artificial survivor quotas.
- The current runtime diet/targeting tables and existing tests allow broader fallback feeding than the older locked-ecosystem document. This audit preserves those explicit runtime choices rather than silently designing a new diet/resource system. Circle consumption of bush health, strict canonical fallback gates and full color/mate preference remain roadmap decisions.
- Current combat intentionally resolves a catch as a kill. Multi-hit combat, wound healing and color-dependent detection are future tracks, not implemented by this audit.
- Terrain generation remains deterministic with its existing derived noise seed. No path planner was introduced: land-only local movement can still become trapped by large water barriers; general navigation is a separate system.
- Smoothing/acceleration coefficients are per-tick values. Changing the tick rate starts a fresh world; it is not a promise of identical trajectories between different TPS configurations.
- Large, mostly unchanged UI/graph/style files still merit future extraction. This PR extracts the large simulation, config and rendering modules needed for these repairs, without redesigning the entire UI.
- No dependency upgrade or security-advisory scan is claimed. The task changes no dependency versions.
